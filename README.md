# Career notes

A private log of work I have shipped, hard stretches, and how I like to build software. The point is a record I can turn into resume bullets and interview stories later.

This is not the Tallo company repository. Company code stays in its own repo.

## How this is organized

- `achievements/` — what shipped, with the evidence I can point at.
- `adversity/` — times the first version was not enough, and what I did next.
- `approaches/` — how I like to work. Written in my own words when I have them.

Each note should say where it came from (commits, a ticket, a doc, a conversation) and the date range. If a number is not in the source, it does not go in the note.
